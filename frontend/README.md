# Portfolify - Frontend

This is the placeholder for the Portfolify frontend workspace.

## Future Tech Stack Recommendation

For a Personal Digital Business Card platform that demands high performance, SEO friendliness (crucial for personal portfolios), and responsive, mobile-first design, we recommend:

1. **Framework**: Next.js (React) or SvelteKit
   - Supports Server-Side Rendering (SSR) or Static Site Generation (SSG) for ultra-fast loading speeds and perfect SEO.
2. **Styling**: Tailwind CSS + Framer Motion (for smooth, premium animations and transitions).
3. **State Management**: Zustand or SWR / React Query for api fetching.
4. **Icons**: Lucide React for rich UI iconography.

## Getting Started

Once the frontend project framework is chosen and initialized:
1. Set up routing.
2. Integrate with the backend Web API endpoints.
3. Configure multi-tenancy resolution (sending the `X-Tenant` header or reading subdomains).
